# 万年历项目收尾总结

## 做了什么

本项目实现了一个可直接打开的中文万年历页面：支持月份前后切换、年份查询、回到今天、公历日期、中文农历（如“正月初一”）以及 2024–2026 年节假日安排标记。页面在桌面和移动端均可使用，并提供节假日“休”和调休上班“班”的视觉区分。

## 关键决策

- 使用浏览器原生 `Intl.DateTimeFormat` 的 `zh-CN-u-ca-chinese` 日历能力展示农历，避免引入体积较大的农历库。
- 节假日不按简单的固定月日或农历节日推算，而是维护国务院办公厅通知中的 2024、2025、2026 年放假区间和调休日数据。
- 数据层以 `节日名称|休/班` 表示状态，渲染层拆分状态，保证展示语义清楚；同日多个节日名称合并。
- 日历计算和页面交互分离，`src/calendar.test.js` 钉住关键日期与官方调休安排。

## 审查中修过的坑

1. 初版把 2024 年春节、端午等日期套用到所有年份，改为按年份维护国办安排。
2. 跨年翻页时节假日表曾缓存初始年份，改为每次渲染按当前年份重新取数。
3. `Intl` 返回数字农历日，初版不是常见中文写法，改为“初一、十五”等传统日名。
4. 2025 年国庆中秋合并假期补充了 10 月 6 日的“中秋节”并列名称。
5. 调休班日曾只有数据标记，补充 `.is-workday` 样式、图例和 2024–2026 全部调休日测试。

## 本地验收

在仓库根目录执行：

```sh
python3 -m http.server 4177 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4177/>。如果端口被占用，改用其他端口即可。开发测试执行 `npm test`，当前测试共 5 项。

## 后续建议

- 将节假日安排抽成独立 JSON/TypeScript 数据文件，并在每年国务院办公厅发布新通知后更新。
- 若需要覆盖更多年份，可接入经审核的权威节假日数据源，并增加数据版本与来源链接。
- 进一步采用 DOM API 替代格子 `innerHTML`，增加键盘焦点、日期选择和更完整的屏幕阅读器描述。
- 增加浏览器自动化测试，覆盖年份查询、跨年导航、休/班视觉状态与移动端布局。
